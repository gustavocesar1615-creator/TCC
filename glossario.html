Glossário tecnológico.

Descubra o significado dos principais termos de programação, internet, segurança digital e inteligência artificial.

✦ 20 conceitos explicados em linguagem simples

Entenda cada conceito

Pesquise por palavra ou escolha um tema para descobrir novos assuntos.

Programação

Algoritmo

Sequência de instruções que orienta um computador a resolver um problema ou executar uma tarefa.

Exemplo: Uma receita organizada em passos é uma boa analogia para um algoritmo.
Internet

API

Conjunto de regras que permite a comunicação entre sistemas e serviços de software.

Exemplo: Um aplicativo pode usar uma API para obter dados de outro serviço.
Segurança

Backup

Cópia de segurança de arquivos e informações para auxiliar na recuperação em caso de perda.

Exemplo: Guardar uma cópia de documentos em outro local.
Internet

Blockchain

Estrutura de registro compartilhado em blocos conectados criptograficamente, utilizada em algumas redes distribuídas.

Exemplo: É uma tecnologia que pode registrar transações e outros dados.
Internet

Computação em nuvem

Uso de recursos computacionais disponibilizados por servidores acessados pela rede.

Exemplo: Armazenar arquivos em serviços online.
Segurança

Criptografia

Conjunto de técnicas para proteger informações por meio de transformações matemáticas.

Exemplo: Conexões seguras usam criptografia para proteger dados transmitidos.
Programação

CSS

Linguagem de estilos usada para definir aparência e layout de páginas web.

Exemplo: É o que define as cores e os espaçamentos do TechNews.
Segurança

Firewall

Ferramenta que controla conexões de rede segundo regras de segurança.

Exemplo: Pode bloquear comunicações não autorizadas.
Programação

HTML

Linguagem de marcação que organiza a estrutura e os conteúdos de páginas web.

Exemplo: Títulos, textos e links do TechNews são estruturados em HTML.
IA

Inteligência artificial

Área da computação dedicada ao desenvolvimento de sistemas que executam tarefas como reconhecer padrões e gerar previsões.

Exemplo: Reconhecimento de imagens e tradução automática.
Programação

JavaScript

Linguagem de programação usada para criar comportamentos interativos em páginas web e em outros ambientes.

Exemplo: Filtros de notícias e botões do TechNews usam JavaScript.
IA

Machine learning

Aprendizado de máquina: métodos que permitem a modelos identificar padrões em dados para realizar tarefas.

Exemplo: Um filtro de spam pode aprender a reconhecer mensagens suspeitas.
Segurança

Phishing

Golpe que utiliza mensagens ou páginas falsas para tentar obter dados pessoais ou credenciais.

Exemplo: E-mails falsos que imitam empresas conhecidas.
IA

Prompt

Instrução ou informação enviada a um sistema de IA para orientar sua resposta.

Exemplo: Pedir que uma ferramenta explique um conceito de forma simples.
Inovação

Realidade aumentada

Tecnologia que combina elementos digitais com a visualização do ambiente físico.

Exemplo: Aplicativos que mostram objetos virtuais pela câmera.
Inovação

Realidade virtual

Tecnologia que oferece experiências em ambientes digitais imersivos.

Exemplo: Simulações e jogos com óculos de realidade virtual.
IA

Rede neural

Modelo computacional formado por unidades conectadas, inspirado de modo simplificado em aspectos de redes biológicas.

Exemplo: Usada em tarefas como reconhecimento de imagens.
Internet

Servidor

Computador ou programa que disponibiliza recursos e informações a outros dispositivos.

Exemplo: Um servidor web entrega páginas aos navegadores.
Programação

Software

Conjunto de programas e instruções que permitem ao computador realizar atividades.

Exemplo: Navegadores, jogos e editores de texto.
Inovação

UX (experiência do usuário)

Área que estuda e projeta a experiência das pessoas ao utilizar produtos e serviços.

Exemplo: Criar uma navegação clara e acessível no site.
